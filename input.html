Input

Input & Keys

Keys are set with a binding, not picked from a dropdown. You press Listen and then the key you want. The same binding works for a gamepad button too, and one component can hold several bindings at once.

Set any key with Listen
Keyboard and gamepad on one event
Works in new Unity 6.3 projects
Getting started

Setting a key

For InputKeyPress and InputKeyCountdown. A newly added component already listens for Space, so it works before you change anything.

  • 1
    Find Activation in the Inspector
    It shows a list of bindings. A new component has one: Space.
  • 2
    Pick the binding, then click Listen
    Click the existing binding to change it, or click + to add another one. In the Path field, click Listen.
  • 3
    Press the key you want
    Unity lists what it heard. Click the key in that list. A gamepad button works the same way.
  • 4
    Wire the event
    InputKeyPress fires On Press Event. Wire it to any function, like ActionPlaySound.Play().
💡
One event, several keys
Add a second binding with + and both keys fire the same event. Bind E and a gamepad button and the game works with either.
Choosing

Which input component?

All of them go through Unity's Input System.

ComponentEventsUse when
InputKeyPressOn Press EventOne key on one object. Nothing else to set up.
InputKeyCountdownOn Count Down Key, On Count Limit KeySomething should happen after a key is pressed a number of times: hit a door five times to break it. Each press counts down by one. The second event fires when the count reaches zero.
InputActionEventOn Action Triggered (+ float and Vector2 versions)You want to use an action from an Input Actions asset, such as one shared by many objects. Drag the action into Action Reference. You choose whether it fires on press, on release, or both.
InputInteractionZoneOn Interact"Press E near this." Uses an Interact action if you assign one, otherwise the Fallback Input Key (E).
Built-in shortcuts

Other keys in the toolkit

Some managers have one shortcut key of their own. These are simple key dropdowns, because they are settings rather than something you wire.

ComponentDefaultWhat it does
GameStateManagerPPause Input Key pauses and unpauses. Escape quits when Quit On Escape is ticked.
GameStoreManagerBStore Input Key opens and closes the store.
InputInteractionZoneEFallback Input Key, used when no Interact action is assigned.
CharacterControllerFPEscapeCursor Toggle Input Key frees and re-locks the mouse cursor.

Character controllers

Player Input

Character controllers read movement through a Player Input component, not a binding of their own. Set its Actions to EGTK_InputSystem_Actions. That asset already has Move, Look, Jump, Sprint, Dodge, Interact and Attack.

⚠️
Only one Player Input per scene
Player Input is built for local multiplayer. With two in a scene, Unity gives the second one a different device, and it can end up waiting for a touchscreen. The character just ignores the keyboard, with no error. If a character will not move, check that it is the only active object with Player Input.
Older projects

Upgrading from the key dropdown

Earlier versions of InputKeyPress and InputKeyCountdown had a key dropdown. That field was replaced, not renamed, so any key you picked before is gone. An upgraded component's Activation list is empty and the key does nothing at all. Add a binding with + and Listen. (Only components added fresh start with Space.)

💡
Why it changed
New Unity 6.3 projects use the Input System only. The old way of reading keys does nothing there. In a fresh project, pressing the key simply never fired the event. Every part of the toolkit now uses the Input System.
