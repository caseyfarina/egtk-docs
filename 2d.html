Making a 2D Game

EGTK works with sprites. Put a Collider 2D on a sprite instead of a Collider and each component works out the rest. There is no 2D checkbox to find.

Platformer or top-down player
Trigger zones, clicks, dragging
Bumpers, force zones, moving platforms
Checkpoints and respawn
How it works

The one rule

A component looks at the collider on its own GameObject. Collider 2D → 2D physics. Collider → 3D physics. That's all it checks.

⚠️
2D and 3D never touch each other
Unity runs 2D and 3D physics as two separate worlds. A 3D bumper cannot push a 2D player, and a 2D trigger never notices a 3D object. Pick one per game. Unity won't let you put a 2D and a 3D collider on the same object either.
Getting started

A 2D player

CharacterController2D moves a sprite. Its Movement Style is Platformer (gravity and jumping) or Top-Down (free movement in every direction). The Inspector hides whichever settings don't apply.

  • 1
    Add Rigidbody 2D and a Capsule Collider 2D
    Put both on your character sprite.
  • 2
    Add Player Input
    Set its Actions to EGTK_InputSystem_Actions. Keep only one Player Input in the scene. See Input & Keys for why.
  • 3
    Add CharacterController2D and pick a Movement Style
    Give the character the Player tag so trigger zones and checkpoints recognise it.
  • 4
    Platformer only: set Ground Layer
    Put your floor objects on their own layer (for example Ground), then set Ground Layer to it. Include the layer your moving platforms use too, or the player can't jump off them.
⚠️
Character won't jump?
Almost always Ground Layer. If it doesn't include the layer your floor is on, the character never feels the ground and jumping never works. Nothing else goes wrong, so it's easy to miss. The Inspector warns when Ground Layer is set to Nothing.
Animation
Animator parameters
Leave Character Animator empty and it finds the Animator on the character or a child. It sets Speed (Float), Grounded (Bool) and VerticalVelocity (Float). Name your Animator Controller's parameters exactly that. Any you leave out are skipped. In Top-Down, Grounded is always true and Speed counts movement in every direction.
Facing
Flipping left and right
One sprite flips on its own. A character made of several sprites (body, arms, legs) needs Visual Root set to the parent that holds the parts, so it flips as one piece. Drew your character facing left? Tick Art Faces Left.
Compatibility

What works in 2D

Components with no physics, like managers, timers, flags, audio, key input and most Actions, work in 2D without any changes. These are the ones that touch physics.
